Gabarit officiel de rapport - Travail Pratique #1

Ce dossier contient les fichiers nécessaires à la rédaction de votre rapport de TP1 :

1. CONTENU DU DOSSIER :
   - gabarit_tp1.tex        : Fichier source LaTeX principal.
   - gabarit_tp1.pdf        : Version PDF compilée de référence.
   - logo_polytechnique.png : Logo officiel haute résolution de Polytechnique Montréal.
   - figure_performances.pdf: Exemple de graphique vectoriel pour illustrer vos résultats.
   - README_GABARIT.txt     : Le présent fichier d'instructions.

2. COMPILATION LOCALE :
   Pour compiler sur votre machine (Linux, macOS, Windows avec TeX Live / MacTeX / MiKTeX) :
   $ pdflatex gabarit_tp1.tex
   $ pdflatex gabarit_tp1.tex (exécuter deux fois pour la table des matières et références)

3. UTILISATION SUR OVERLEAF :
   - Rendez-vous sur https://www.overleaf.com
   - Cliquez sur "New Project" -> "Upload Project"
   - Glissez-déposez cette archive zip complète (gabarit_tp1_latex.zip)
   - Vérifiez que le compilateur est bien réglé sur "pdfLaTeX" (par défaut)
   - Cliquez sur "Recompile"

4. RAPPELS IMPORTANTS CONCERNANT LE RAPPORT (ÉVITEZ LES PÉNALITÉS !) :
   - Limite stricte : 10 pages MAXIMUM (annexes comprises). Tout dépassement entraîne -0,5 pt/page.
   - Respect du gabarit : Conservez la police, l'interligne et les marges de 2 cm (pénalité de -1 pt si non respecté).
   - Figures et graphiques : Chaque figure DOIT comporter une légende explicative ET des unités claires (ex: [%], [Ko], [bits/symbole], [ms]). Pénalité de -0,5 pt par élément sans légende ou unité.
   - Tableaux : Chaque tableau doit être numéroté, légendé et inclure les unités de mesure.
   - Références : Citez explicitement vos sources et librairies externes (-0,5 pt si omis).
   - Format de remise : Seul le format PDF est accepté pour le rapport, inclus dans votre archive (.zip ou .7z) avec votre code source complet.
